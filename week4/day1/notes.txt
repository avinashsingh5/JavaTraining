Types of relationship in java :
    1.HAS-A relationship 
    2.IS-A relationship

HAS-A relationship :
    1.Aggregation
        is a weak HAS-A relationship where the child object is created outside the parent class and can exist independently
    2.Composition
        is a strong HAS-A relationship where the parent class creates and owns the child object , and the child cannot exist independently.

    Inheritance: 

    single level Inheritance: One sub class having only one super class
    Multi level Inheritance: One sub class is having more than one super class at different level
    hierarichal Inheritance: One super class is having more than one subclass at same level 
    multiple Inheritance: one subclass is having morethan one super class at same level is known as multiple Inheritance
        In java we can not achive multiple Inheritance with the help of class
        because of diamond problem.
        To achive multiple Inheritance in java we have to use interface

    Hybrid Inheritance: combination of any two Inheritance is called Hybrid Inheritance.
