Stream:
    Stream is a java 8 feature used to process collection data in functional way without using loops.
    Stream was introduced in java 8
    Stream does not store data
    It works on collection data
    Stream processes datat one by one
    Stream does not change original collection

Basic steram flow : collection -> stream -> Opeartion ->Result
eg: List-> Stream() -> filte() -> forEach()
